🔐 پسوردبان

پسوردبان یک برنامه ساده و کاربردی برای مدیریت و نگهداری امن رمزهای عبور در اندروید است.

🎯 هدف پروژه این است که یک ابزار ساده، رایگان و بدون تبلیغات برای مدیریت رمزها در اختیار کاربران قرار دهد.

✨ امکانات

- 🔑 ساخت رمزهای امن و پیچیده
- 🔐 ذخیره‌سازی اطلاعات به‌صورت محلی روی دستگاه
- 📱 رابط کاربری ساده و کاربردی
- 🚫 بدون تبلیغات
- 🆓 کاملاً رایگان
- 🖼️ امکان انتخاب تصویر برای پسوردها
- 📋 امکان کپی کردن عنوان و اطلاعات پسورد
- 🎨 پشتیبانی از تم‌های مختلف

🤝 مشارکت در توسعه

این پروژه با هدف توسعه و بهبود مستمر منتشر شده و از مشارکت سایر توسعه‌دهندگان استقبال می‌کنم.

اگر ایده‌ای برای بهبود پروژه دارید، باگ پیدا کرده‌اید یا می‌خواهید قابلیت جدیدی به پسوردبان اضافه کنید، خوشحال می‌شوم در توسعه آن مشارکت کنید.

نحوه مشارکت

1. پروژه را Fork کنید.
2. تغییرات موردنظر خود را در Fork خود اعمال کنید.
3. تغییرات را Commit و Push کنید.
4. یک Pull Request به این Repository ارسال کنید.
5. من Pull Request شما را بررسی می‌کنم و در صورت مناسب بودن، آن را در پروژه اصلی قبول و Merge خواهم کرد.

💙 از هرگونه مشارکت، پیشنهاد، رفع باگ و توسعه قابلیت‌های جدید استقبال می‌کنم.

🐛 گزارش باگ

اگر مشکلی در برنامه پیدا کردید، می‌توانید یک Issue ایجاد کنید و موارد زیر را در آن بنویسید:

- توضیح مشکل
- مراحل ایجاد مشکل
- نسخه اندروید
- مدل دستگاه
- در صورت امکان، تصویر یا ویدئوی مشکل

🚀 ایده‌های توسعه

اگر ایده‌ای برای بهتر شدن پسوردبان دارید، می‌توانید آن را در قالب یک Issue مطرح کنید یا مستقیماً روی پروژه کار کرده و Pull Request ارسال کنید.

هر پیشنهاد و مشارکتی می‌تواند به بهتر شدن پروژه کمک کند.
